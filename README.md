# sole for Windows: releases

Installers for [sole](https://heysole.app), a to-do app with a pixel buddy at the top of your screen.
Download the latest from [Releases](https://github.com/wajahatkarim3/sole-releases/releases/latest):
`Sole_<version>_x64-setup.exe` for most PCs, `Sole_<version>_arm64-setup.exe` for Windows on Arm.

Installed copies update themselves from `latest.json` here. The source lives elsewhere; this repo only holds releases.
Questions or bugs: wajahat@heysole.app
